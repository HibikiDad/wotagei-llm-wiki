# S11b LUMICA 官網「化学発光体について」

網址：<https://www.lumica.co.jp/about_cl>。S11a～S11c 是 LUMICA 官網的三個頁面，綁成一組來源。
全文只保存在本機；後設資料與短引文：[raw/web/S11b-lumica-about-chemical-light.md](../../raw/web/S11b-lumica-about-chemical-light.md)。

## 一句話摘要

製造商對化學螢光棒的說明：為什麼會亮、怎麼保存、液體外漏時怎麼處理、有沒有毒。

## 重點（經使用者確認）

1. **原理**：輕輕折彎棒子，內部的玻璃安瓿破裂，「酸化液」與「蛍光液」兩種化學物質起反應而發光；發光時不發熱，所以叫「**冷光**」。不需要電池、不用火。
2. **熄滅後不能再用**：化學反應結束就不會再亮；包裝上寫的「發光時間」是指**維持實用亮度**的時間，超過時間仍可能微微發光。
3. **保存**：怕光、熱、濕氣，放在陽光照不到、乾燥的地方；強烈撞擊可能讓安瓿破裂、提早發光；拆開鋁袋後盡早使用。
4. **不要加熱或冷凍**：明火、吹風機、熱水加溫可能破損；放冷凍庫可能讓內容物析出、外管變脆而漏液。
5. **液體外漏時**：進到眼睛 → 絕對不要揉，用流水沖，發癢或充血就就醫；沾到皮膚 → 用水或肥皂水洗；沾到衣服 → 可能留下污漬，可乾洗；沾到家具 → 可能留下污漬或溶解部分塑膠；外漏的液體用紙巾吸起來，裝進聚乙烯袋封好再丟。
6. **有沒有毒**（廠商說法）：沒有使用法律指定的毒物、劇物；有害性約等於中性洗劑（經第三方機構驗證）；引火性極低，也沒有會爆炸的成分。小孩使用時要有大人陪同。
