# S11c LUMICA 官網「沿革」

網址：<https://www.lumica.co.jp/aboutus/history>。S11a～S11c 是 LUMICA 官網的三個頁面，綁成一組來源。
全文只保存在本機；後設資料與短引文：[raw/web/S11c-lumica-history.md](../../raw/web/S11c-lumica-history.md)。

## 一句話摘要

LUMICA 從 1978 年創業到 2021 年的公司沿革，包含取得サイリューム銷售權、推出ルミカライト與大閃光系列、サイリウムダンス獲獎。

## 重點（經使用者確認）

1. **1978** 年創業，開始研究化學發光體；**1979** 年成立「日本化学発光株式会社」，推出釣魚用的「ケミホタル」。
2. **1982** 年與美國 American Cyanamid（アメリカン・サイアナミッド）簽下「**サイリューム**」的獨家銷售合約；**1983** 年再簽化學發光體的製造銷售合約。
3. **1993** 年推出「ルミカライト」（註冊商標）；**2001** 年改名為「株式会社ルミカ」。
4. **2012** 年推出有增亮功能的多色 LED 螢光棒「LUMI ACE」。
5. **2017** 年「大閃光ペイント」誕生；**2018** 年推出「大閃光８（エイト）」。
6. **2019** 年「サイリウムダンス」在第 46 回 MAF展獲得「文部科学大臣賞」（MAF展是什麼，來源沒有說明，使用者也不清楚，[S00](S00-discussion-notes.md)）。

## 這份來源特別適合用來說明

- 「サイリューム」這個商標怎麼進入日本（呼應 [S04a](S04a-ja-wiki-chemical-light.md) 的「サイリューム是商標」）
- サイリウムダンス（表演藝）得到官方獎項的紀錄

## 可信度與限制

- 公司沿革只列事件，沒有細節；MAF展、獲獎的對象（誰得獎）沒有說明。
