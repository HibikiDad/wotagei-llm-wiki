# S00 使用者討論紀錄

原始資料：[raw/discussion/discussion-notes.md](../../raw/discussion/discussion-notes.md)（只追加不修改）。

每次 ingest 時，Claude 會先提出重點讓使用者確認（「先討論、後生成」）。使用者的修正與補充屬於圈內的實務知識，記錄在這裡，讓 wiki 中來自使用者的說法也能被追溯。

## 各次討論的重點

### S01 討論（2026-11-23）

1. **應援型要分成兩種，不能統稱地下藝**：
   - **一般應援**：拿著螢光棒在觀眾席上應援。
   - **地下藝**：用極度誇張、扭曲、甚至噁心的動作，加上 MIX，來吸引台上表演者注意的應援方式。
2. **三者的總稱是「御宅藝」**；表演型叫「表演藝」，「地上藝」與「サイリウムダンス」列為別名。
3. **技名**：標準寫法保留日文原名，旁邊附中文意譯；台灣圈口語通常直接念中文。
4. 打つ → 打藝、打ち師 → 打師；「地蔵（タイガー）」待確認；家虎歸類為概念；S01 可信度評為中 —— 均同意。

### S02 討論（2026-11-23）

1. **台灣的地下藝大多出現在地下偶像的應援場合**；台灣御宅藝圈的資料之後會再 ingest。
2. 「地下藝」的「地下」與地下偶像**大概率有關**，等之後有資料再證實（目前標為未證實）。
3. 其餘重點與頁面規劃 —— 同意。

### S03 討論（2026-11-23）

1. **在地偶像與地下偶像分成兩頁**（S03 把兩者視為同義，本 wiki 不採用）。
2. 同意寫入整理者推論：秋葉系現場歌迷少、多團同場、距離近 → 表演者認得出個別粉絲 → 這是地下藝以「吸引表演者注意」為目的的背景。
3. 其餘重點與頁面規劃 —— 同意。

### S04 討論（2026-11-23）

1. 用語表同意；**LED 螢光棒在台灣也叫「手燈」**，要記錄下來。
2. 螢光棒**合併成一頁**（gear/glowstick.md）。
3. **台灣現場以 LED 螢光棒為主**，因為演唱會可能禁止化學螢光棒。
4. （可信度評估未回覆，沿用提議；之後在 S05 討論時改為：S04a、S04b 都是**中**。）

### S05 討論（2026-11-23）

1. **地下藝通常不拿螢光棒**（同意 S05 的說法）；「打call」對應到一般應援（→ 在 S06 討論時修正，見下）。
2. 十字架的日文是**ロザリオ**；副歌技是**サビ技**；ギニュ～特戦隊在台灣常稱「**基扭特戰隊**」。
3. 影片中的**小祈就是 S08 的「祈哥」**（討論時稱 S07，之後重新編號）。
4. 新增副歌技頁、大幅更新台灣頁 —— 同意；S05 可信度評為**高**。

### S06 討論（2026-11-23）

1. **打call 是總稱**：不是專指一般應援，地下藝也歸類在打call 中；MIX 也是打call 的一種方式（**修正 S05 討論時的說法**）。
2. **MIX 不是地下藝專有**：一般偶像也可能在歌曲中放入粉絲記得住的專屬口號當作 MIX。
3. **地下藝的 call** 有時候跟偶像本身沒有關係，而是約定俗成的一套念法，讓好幾個人的聲音大到讓偶像注意到。
4. **「虎火三連」是最常使用的 MIX**；喊詞與寫法參考使用者提供的 kknews 文章（→ S07）。
5. 曲子段落以「日文原名＋中文」為標準寫法，例如 Aメロ（主歌）、Bメロ（導歌）、サビ（副歌）。

### S07 討論（2026-11-23）

1. **「虎火三連」就是英語、日本語、愛努語三種接著喊的一般三連MIX**（不是 S07 的「虎火發動」）。
2. 「woo hey」「Urya-Hi」這類喊聲**直接寫羅馬音**。
3. **在台灣，喊家虎、打地下藝會被當成厄介**。
4. 厄介的日文來源之後再補（S09）。
5. S07 可信度評為**高**。
