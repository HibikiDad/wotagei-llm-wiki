# 曲子結構與打法

**偶像歌曲大致由前奏、Aメロ（主歌）、Bメロ（導歌）、サビ（副歌）、間奏、Cメロ、尾奏組成；現場要喊什麼、打什麼，跟著段落走。**要會喊 MIX，先要會分辨歌曲段落（[S06c](../sources/S06c-dLfZSCgwyMY.md) 影片說明）。

## 段落名稱（標準寫法）

| 標準寫法 | 意思 |
|---|---|
| 前奏 | 歌聲開始前的器樂段落 |
| Aメロ（主歌） | 第一段旋律 |
| Bメロ（導歌） | 接往副歌的過渡旋律 |
| サビ（副歌） | 歌曲最高潮、重複的段落 |
| 間奏 | 段與段之間的器樂段落 |
| Cメロ | 二段副歌之後、通常速度變慢的新段落 |
| 尾奏 | 最後一段副歌之後的結尾 |

段落名稱以日文原名＋中文為標準寫法（[S00](../sources/S00-discussion-notes.md)）。

## 各段落喊什麼（2018 年的現場）

| 段落 | 喊什麼／做什麼 | 出處 |
|---|---|---|
| 前奏 | 先喊「woo hey」抓拍子 → 發動 [MIX](../concepts/mix.md)；前奏夠長可以喊三連MIX | [S06c](../sources/S06c-dLfZSCgwyMY.md) 00:30～01:01 |
| 前奏（輕拍子） | 在拍子轉重、喊 Urya-Hi 之前喊 MIX，前面先喊「Hi-seno」 | [S06b](../sources/S06b-yzX_SkMQAfw.md) 02:10 |
| 前奏／二段主歌前 | 假發動「まだいかない」×2 → 英語或日本語 MIX | [S06b](../sources/S06b-yzX_SkMQAfw.md) 02:45～03:15 |
| Aメロ（主歌） | 「ニーハイ、オイハイ」：配合穿長襪的動作、拍手，最後跳起來喊「I can fly」—— 動作跟ヲタ芸很像，只是沒拿螢光棒 | [S06b](../sources/S06b-yzX_SkMQAfw.md) 04:52 |
| Bメロ（導歌） | 歌曲進行中也會喊 MIX，一般在導歌 | [S06c](../sources/S06c-dLfZSCgwyMY.md) 03:07；[S06b](../sources/S06b-yzX_SkMQAfw.md) 05:26 |
| 句與句之間 | 倍速MIX | [S06c](../sources/S06c-dLfZSCgwyMY.md) 02:27 |
| サビ（副歌）前的空檔 | [家虎](../concepts/yetta-tiger.md)：前一句先喊兩聲「耶」預備 | [S06c](../sources/S06c-dLfZSCgwyMY.md) 03:49～04:26 |
| 二段副歌 → 三段副歌之間 | 2018 年流行的某個 MIX（字幕沒有打出名稱） | [S06b](../sources/S06b-yzX_SkMQAfw.md) 07:06 |
| Bメロ → 尾奏 | ガチ恋口上、可変3連MIX；尾奏喊完「あいしてる」可再接「絶対結婚しような」 | [S06b](../sources/S06b-yzX_SkMQAfw.md) 07:49～08:20 |
| Cメロ（速度變慢） | 用兩聲「wa」起手的 MIX，聽起來很有力 | [S06b](../sources/S06b-yzX_SkMQAfw.md) 08:54 |
| 曲尾 | 一樣拍手 5 下，但起手改喊「pa～mosu」 | [S06b](../sources/S06b-yzX_SkMQAfw.md) 04:22 |
