# 御宅藝年表

**御宅藝從 1970～80 年代偶像親衛隊的齊聲應援出發，在 2000 年代成形、2010 年代分化出表演藝。**

| 年代 | 事件 | 出處 |
|---|---|---|
| 1974 夏 | 西城秀樹在大阪球場請觀眾帶手電筒，演唱會揮光文化的起源（→ [螢光棒](../gear/glowstick.md)） | [S04b](../sources/S04b-ja-wiki-penlight.md) |
| 1970～80 年代 | 偶像親衛隊配合歌曲齊聲喊聲的應援風格已經存在 | [S01](../sources/S01-ja-wiki-wotagei.md) |
| 1986 | 偶像演唱會已多半從燈泡式改用化學螢光棒 | [S04b](../sources/S04b-ja-wiki-penlight.md) |
| 1989-11-22 | 渡辺美奈代〈恋愛紅一点〉發售；A メロ時粉絲跳的「[ロマンス](../techniques/romance.md)ダンス」被視為オタ芸的發源與原型 | [S01](../sources/S01-ja-wiki-wotagei.md) |
| 1993 | 吉本興業推出「大阪勁舞娃娃」「阿波勁舞娃娃」（[在地偶像](../concepts/local-idol.md)的先聲） | [S03](../sources/S03-zh-wiki-local-idol.md) |
| 1993 | 🇹🇼 台灣首個大規模同人誌即賣會 | [S02](../sources/S02-zh-wiki-taiwan-underground-idol.md) |
| 1995 | COCONUT'（ココナッツJr.）成軍，被視為在地偶像的原型 | [S03](../sources/S03-zh-wiki-local-idol.md) |
| 1996 起 | 「地方出道的偶像」大量出現（りんご娘、SHIP 等） | [S03](../sources/S03-zh-wiki-local-idol.md) |
| 1996-06 | やまと工業推出 5 色 LED「チアライト」，被ジャニーズ採用 | [S04b](../sources/S04b-ja-wiki-penlight.md) |
| 1997-12-09 以前 | 電視節目《ナイナイナ》播出オタ芸的樣子（最晚的全國播出紀錄）；在這之前水野あおい的演唱會就有オタ芸 | [S01](../sources/S01-ja-wiki-wotagei.md) |
| 2000 年代 | 應援加入舞蹈、變得多樣化，在ハロー!プロジェクト的演唱會上以「オタ芸」之名被認知 | [S01](../sources/S01-ja-wiki-wotagei.md) |
| 2002 | 🇹🇼 Comic World Taiwan（CWT）、開拓動漫祭（FF）開辦 | [S02](../sources/S02-zh-wiki-taiwan-underground-idol.md) |
| 2002 前後 | 音樂祭上粉絲在推的團上場時才折 UO（ウルトラオレンジ） | [S04b](../sources/S04b-ja-wiki-penlight.md) |
| 2002-09-04 | 〈ロマンティック 浮かれモード〉發表，成為オタ芸數年間擴散到一般大眾視野的契機 | [S01](../sources/S01-ja-wiki-wotagei.md) |
| 2004-06-16 | 🇹🇼 台灣第一家女僕咖啡廳「咖啡安妮莓」開幕，有地下偶像唱跳表演 | [S02](../sources/S02-zh-wiki-taiwan-underground-idol.md) |
| 2005 | 日劇《電車男》播出刻板的宅男形象；2000 年代末以前，偶像應援常被批評「幼稚」「缺乏常識、危險」 | [S01](../sources/S01-ja-wiki-wotagei.md) |
| 2006 起 | 透過 YouTube、ニコニコ動画擴散，一般人也開始認識 | [S01](../sources/S01-ja-wiki-wotagei.md) |
| 2007 | J 聯盟川崎前鋒的選手在粉絲感謝日表演「ンタ芸」 | [S01](../sources/S01-ja-wiki-wotagei.md) |
| 2008 | 榊原ゆい在自己的 live 全面禁止オタ芸 | [S01](../sources/S01-ja-wiki-wotagei.md) |
| 2009 | 據 S05，基扭特戰隊（ギニュ～特戦隊）開始形成用螢光棒表現的御宅藝文化（[表演藝](../concepts/performance-gei.md)） | [S05](../sources/S05-K97ZqVhf-mA.md) |
| 2010 前後 | 觀眾自備多色螢光棒對應成員代表色（應援色）；無線控制 LED 螢光棒出現，2013 年起普及 | [S04b](../sources/S04b-ja-wiki-penlight.md) |
| 2011 起 | 🇹🇼 各地方政府紛紛舉辦「動漫節」，表演機會變多 | [S02](../sources/S02-zh-wiki-taiwan-underground-idol.md) |
| 2011 | 🇹🇼 台北電玩展上「戰鬥哥」在 MEGA 舞台下應援的影片爆紅（觀看數 400 萬），帶動很多人入坑 | [S10a](../sources/S10a-evolution-home.md) [S05](../sources/S05-K97ZqVhf-mA.md) |
| 2014 前後 | 以打藝為主體的活動與 live 頻繁舉辦（[表演藝](../concepts/performance-gei.md)成形） | [S01](../sources/S01-ja-wiki-wotagei.md) |
| 2015 | AKB48 禁止帶入化學螢光棒；2020 年代 LED 螢光棒成為主流 | [S04b](../sources/S04b-ja-wiki-penlight.md) |
| 2017-08 | 神戸 KOBerrieS♪ 演唱會訴訟（打藝太激烈、聽不到歌） | [S01](../sources/S01-ja-wiki-wotagei.md) |
| 2017 | 日本打師 ROTO 成為「初代御宅藝世界王者」 | [S10c](../sources/S10c-evolution-competition.md) |
| 2017-10 | 三連MIX、家虎、厄介的中文解說文章（S07）；文中描述偶像劇場喊家虎會被當成厄介（場景推測為中國，整理者推論） | [S07](../sources/S07-kknews-mix.md) |
| 2018 | 基扭特戰隊與 LUMICA 合辦「Cyalume Dance World Battle」（有台灣區選拔賽）；🇹🇼 EvolutioN 在高雄成立 | [S10c](../sources/S10c-evolution-competition.md) [S10a](../sources/S10a-evolution-home.md) |
| 2018-08 | 🇹🇼 新竹高中動畫社在社團博覽會表演ヲタ芸，之後發展成風城界隈 | [S05](../sources/S05-K97ZqVhf-mA.md) |
| 2018-12 | 🇹🇼 台灣 WOTA 無用男Rain 上傳 MIX 教學；家虎在偶像現場「幾乎是必備知識」 | [S06b](../sources/S06b-yzX_SkMQAfw.md) |
| 2019～2020 初 | 🇹🇼 疫情使粉絲無法出國看日本 live，轉而關注台灣本土[地下偶像](../concepts/underground-idol.md) | [S02](../sources/S02-zh-wiki-taiwan-underground-idol.md) |
| 2020-01 | 🇹🇼 風城界隈創團；祈哥上傳〈新手村入門〉表演藝中文教學 | [S05](../sources/S05-K97ZqVhf-mA.md) [S08a](../sources/S08a-zGVnPOHCoRA.md) |
| 2020-02-02 | ブシロード木谷高明宣布根絕[家虎](../concepts/yetta-tiger.md) | [S01](../sources/S01-ja-wiki-wotagei.md) |
| 2021 | 🇹🇼 EvolutioN 舉辦「Mega 戰鬥哥十週年紀念」 | [S10a](../sources/S10a-evolution-home.md) |
| 2022、2023 | 🇹🇼 EvolutioN 與高雄捷運合辦御宅藝螢光棒舞蹈大賽（→ [比賽](../culture/competitions.md)） | [S10c](../sources/S10c-evolution-competition.md) |
| 2024-08-10 | 🇹🇼「駁二光流祭 御宅藝螢光棒舞蹈大賽」 | [S10c](../sources/S10c-evolution-competition.md) |
| 2025 | 🇹🇼 EvolutioN 赴日參加煌芒祭，演出使用 12 個[台灣原創技](../techniques/taiwan-original-waza.md) | [S10d](../sources/S10d-evolution-taiwan-original-waza.md) |

🇹🇼 = 台灣的事件，詳見[台灣的地下偶像與御宅藝圈](../culture/taiwan.md)。

> ⚠️ 資料缺口：台灣御宅藝（粉絲方）的時間線目前只有 S05、S10 兩份來源，而且出自同一團隊；高雄藝師聯合等早期團體的年份不明。
